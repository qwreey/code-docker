### xterm 하단 잘림 — 원인 확정, 수정됨 (번들 `index-_be9OZs9.js` / CSS `index-Cev-21gl.css`)

프로덕션 실측으로 원인이 산수까지 맞아떨어졌습니다. `index.css:192-196`이 전역
`box-sizing: border-box`를 걸어두는데, Chrome은 그 경우 `getComputedStyle().height`로
**border box**를 돌려줍니다. FitAddon은 그 값을 컨테이너의 *콘텐츠* 높이로 믿고
행 수를 계산하므로, `.terminal-container`에 있던 패딩만큼 행이 과하게 잡혔습니다:

```
getComputedStyle(container).height  384.233   <- FitAddon이 읽는 값
container padding                   6px / 0px
.xterm height                       378.233   <- 384.233 - 6, 실제
.xterm padding                      0 / 0     <- 뺄 게 없음
rows / cellH                        24 / 16
.xterm-screen height                384       <- 24 * 16
초과                                5.767px   = 0.36행, overflow:hidden에 잘림
```

**잘린 양 = 컨테이너의 세로 패딩.** 기기별 편차도 이걸로 설명됩니다(패딩은 rem,
