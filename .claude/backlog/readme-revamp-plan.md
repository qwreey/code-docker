# README.md 재단장 계획 (아이디어 단계 — 착수 전)

## 배경

README.md가 담고 있던 실사용 문서(설치법, 각 통합별 tips, webmanager 기능
소개 등)를 `docs/index.md` + `docs/*.md`로 전부 옮김(2026-08-05). 이유:
나중에 이 문서들을 webmanager 안에서도 볼 수 있게 하려면(빌드 시 `docs/`를
webmanager 정적 자산으로 복제해서 렌더하는 방식이 유력해 보임 — 자세히는
`webmanager/.claude/research/guide-plan.md`) 문서가 `docs/` 밑에 모여 있는
쪽이 유리함. 이 문서 이동 자체는 이미 끝났음 — 여기서 다루는 건 그 다음
단계, 짧아진 README.md 자체를 다듬는 일.

## 지금 상태

README.md는 제목 + 스크린샷 + 짧은 소개 문단(GCC/openssh 포함) + 빌드
커스터마이징 링크 + "문서화" 섹션(`docs/index.md`로 안내)만 남음(14줄).

  최신 릴리즈, Docker 이미지 크기 등.
- **짧은 소개 다듬기**: 처음 보는 사람이 몇 초 안에 "뭐 하는 프로젝트인지"
  파악할 수 있는 수준으로.
