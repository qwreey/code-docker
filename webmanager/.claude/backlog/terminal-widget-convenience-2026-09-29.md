# 터미널/위젯 편의성 묶음 (2026-09-29, 사용자 노트)

아직 착수 전. 한 번에 묶어서 처리하거나 서브에이전트로 넘길 수 있는 크기다.

1. **위젯 아이콘이 테마를 안 따름** — 다크 테마에서 아이콘이 검정으로 나와 안 보인다.
   아이콘 색이 `currentColor`/테마 토큰이 아니라 고정값인 곳을 찾을 것.
2. **탭 포커스 시 터미널 크기 갱신이 위젯에서는 안 되는 듯** — 일반 터미널 탭은 포커스되면
   크기를 다시 맞추는데, 위젯(code-server 쪽 bottom view 포함?)에서는 그 경로가 안 타는 것으로 보임.
   재현 경로부터 확인.
3. **새 탭 여는 버튼이 없음** — webmanager bottom view에는 세션 바꾸기만 있고, 팔레트를 열지
   않고는 탭을 하나 더 열 방법이 없다. bottom view에 "새 터미널" 버튼 추가.
4. **webmanager로 새로 연 터미널 세션은 기본 pin** — 반대로 사용자가 직접(일반 code 터미널처럼)
   연 세션은 나가도 사라지지 않는 쪽이 자연스럽다. 두 진입 경로의 기본값을 나눌 것.
   현재 pin 동작/세션 수명 규칙은 `internal/termsession`과 code-server 확장의 슬롯 로직 참고.
